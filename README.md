# WorklyOS — Employee Attendance Tracker

WorklyOS is a modern employee attendance and workforce management application built with React, TypeScript, and Vite.

It provides a practical interface for managing employees, recording daily attendance, monitoring workforce activity, and reviewing attendance history.

## Features

- 📊 Attendance dashboard with workforce insights
- 📝 Daily attendance sheet
- 🖥️ Employee attendance kiosk
- 👥 Employee roster management
- 📅 Attendance history
- 🔎 Attendance and employee information views
- 🌙 Light and dark theme support
- 💾 Local browser storage for attendance and employee data
- 📱 Responsive interface for desktop and tablet screens
- ✨ Smooth UI interactions and animations

## Technology Stack

- **React**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **shadcn/ui**
- **Framer Motion**
- **Lucide / Phosphor Icons**
- **Sonner**
- **React Router**
- **date-fns**
- **Recharts**
